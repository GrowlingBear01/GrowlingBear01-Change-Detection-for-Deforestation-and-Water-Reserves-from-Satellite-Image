# 🌍 Change Detection for Deforestation and Water Reserves using Satellite Images  

## 📚 Project Overview  
This project focuses on detecting **deforestation and water body changes** from satellite images using a **U-Net deep learning model**. The model processes **NDVI (Normalized Difference Vegetation Index) and NDWI (Normalized Difference Water Index)** maps to analyze environmental changes over time.  

## 🚀 Features  
- ✅ **Automatic Change Detection** for forests and water bodies.  
- ✅ **Deep Learning-Based U-Net Model** for segmentation.  
- ✅ **Satellite Image Preprocessing** with NDVI & NDWI.  
- ✅ **Google Earth Engine Integration** for data extraction.  
- ✅ **Streamlit Web App** for interactive usage.  

## 📊 Dataset  
- **Satellite Data**: Extracted using Google Earth Engine (Sentinel-2).  
- **Regions Covered**: **Manipur, Assam, Arunachal Pradesh (Northeast India)**.  
- **Preprocessing**: Cloud masking, NDVI & NDWI computation, resizing to 256×256.
- **Dataset Link**: https://drive.google.com/drive/folders/1JXLtZz2apVl0W_J42jTKdb2ZFouynJsh?usp=sharing


## 🛠️ Technologies Used  
- **Deep Learning**: TensorFlow, Keras, U-Net  
- **Data Processing**: NumPy, OpenCV, Matplotlib  
- **Satellite Data Extraction**: Google Earth Engine  
- **Web Deployment**: Streamlit
